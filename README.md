# Mount-EFI-for-MacOS
A GUI MacOS app to mount EFI partitions

This is my first MacOS app and my first time posting here, so please be gentle. I would love for people to download, run and test it, then feel free to give feedback. I have used command scripts and terminal apps for mounting EFI partitions and they are fine. I wanted to create an app that does not require terminal or commands and accomplishes the same result. I also want to avoid having the user install dependencies.

Please let me know what you think.
